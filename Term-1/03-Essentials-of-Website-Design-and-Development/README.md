> Diploma in Digital Marketing · Term 1 · 10 sessions × 2 hours · [⬅ Term Home](../README.md)

Every campaign lands somewhere, usually on a web page. This module gives marketers the hands-on web skills they need: writing clean HTML5, styling with CSS3, laying out responsive pages, building lead forms and media sections, and adding a touch of JavaScript and the GA4 tag. All examples are small, commented and runnable, and the module ends with a published, measurable landing page.

## 🎯 What You Will Learn

- Explain how the web works, the evolution of HTML and the roles of HTML, CSS, JavaScript and jQuery
- Write valid HTML5 pages with headings, formatting, lists, links, anchors and entities
- Style pages with CSS3 selectors, classes, IDs, fonts, the box model and positioning
- Build responsive layouts with semantic elements, Flexbox and media queries
- Create HTML5 lead forms with validation and add images, video, audio and embeds
- Publish a landing page with a GA4 lead event

## 📋 Prerequisites

- Modules 01-02 recommended (landing page and SEO ideas)
- Comfortable with files and folders on a computer; no programming experience needed

## 🚀 Module Mini-Project

**Responsive Business Website + Campaign Landing Page:**

1. A 4-page site (Home, Services, About, Contact) with semantic HTML and one shared external CSS file
2. Consistent navigation, anchors, tel/WhatsApp/email links
3. A pricing or services section with cards and a highlighted option
4. A contact page with a validated form and an embedded map
5. A separate campaign landing page with a lead form, JavaScript validation and a GA4 `generate_lead` event
6. Zero errors in the W3C validator; tested on desktop and a real phone
7. Published on a free host; submit the live links
