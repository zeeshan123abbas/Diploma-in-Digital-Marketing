# Technical SEO Audit Checklist

Website: ______________________  Date: ________  Auditor: ________________

## Indexing
- [ ] `site:` search shows the important pages
- [ ] No test/staging/duplicate pages in the index
- [ ] robots.txt exists and does not block important sections
- [ ] XML sitemap exists and lists live pages only

## Crawl health
- [ ] No 4xx broken internal links
- [ ] No 5xx server errors
- [ ] Redirects are 301 and not chained (A→B→C)
- [ ] Important pages reachable within 3 clicks

## Metadata
- [ ] Every page has a unique title (50-60 characters)
- [ ] Every page has a meta description
- [ ] One H1 per page
- [ ] Canonical tags present and correct
- [ ] Images have alt text

## Speed and mobile
- [ ] Viewport meta tag present
- [ ] Mobile performance score recorded: ____
- [ ] LCP ____ s (target ≤ 2.5 s)  INP ____ ms (≤ 200)  CLS ____ (≤ 0.1)
- [ ] Images in modern formats/compressed
- [ ] Text readable and buttons tappable on a phone

## Security and markup
- [ ] HTTPS with valid certificate
- [ ] http:// redirects to https://
- [ ] Structured data detected and valid (type: ________)
- [ ] CMS and plugins appear up to date (no warnings)
