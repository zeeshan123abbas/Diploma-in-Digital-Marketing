# 5-Slide Pitch Outline

| Slide | Headline (write as a full sentence) | Content | Speaker note |
|---|---|---|---|
| 1. Hook | | One surprising number or question | |
| 2. Problem | | The client's pain, 2-3 bullets | |
| 3. Solution | | Screenshot of the website + 3 key features | |
| 4. Plan | | Next 4 weeks: tasks, budget (PKR), KPIs | |
| 5. Ask | | What you want approved and by when | |

## Rehearsal checklist
- [ ] Practised out loud at least twice
- [ ] Under the time limit
- [ ] First and last sentence memorised
- [ ] Every slide has a sentence headline
- [ ] Font 24 pt or larger
- [ ] Answers ready for: budget, timeline, risks
